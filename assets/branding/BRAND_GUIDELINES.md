> **Version:** 1.0

## 1. Brand Concept & Identity

**MLForge** represents a modern digital forge for machine learning engineering. Just as a physical forge refines raw materials through heat and pressure into precision-engineered tools, **MLForge** transforms raw data through automated feature engineering, multi-model benchmarking, and cross-validation into robust, explainable, production-ready ML systems.

### Core Brand Values
- **Engineered Precision**: Rigorous methodology, leakage-free pipelines, and reproducible results.
- **Developer-Centric**: Minimalist, high-performance, and high-signal developer experience.
- **Transparency & Explainability**: Native interpretability, feature attribution, and scenario simulation.
- **Enterprise Modernity**: Sophisticated, clean SaaS aesthetics without visual clutter or generic AI gimmicks.

## 2. Symbol Design & Geometry

The official **MLForge** mark is an isometric **3D Hexagonal Ribbon "M"** accompanied by floating data transformation pixels:

1. **Left Ingestion Pillar** (`#fbcb97` → `#e78a53` with `#fbcb97` top isometric lid): Represents raw data ingestion and exploratory data analysis. The top facet reflects incoming computational flux.
2. **Center Interlocking Ribbon Folds** (`#5f8787` → `#527575` descending and ascending): Represents the core automated feature engineering and model training crucible, interweaving inputs into unified architectures.
3. **Right Deployment Arch & Pillar** (`#e78a53` → `#d87943`): Represents trained model deployment, explainability (SHAP), and real-time inference playgrounds.
4. **Bottom Terracotta Anchor** (`#9e4e24`): Provides foundational structural weight to the isometric ribbon.
5. **Floating Transformation Pixels** (`#fbcb97`, `#e78a53`, `#5f8787`): Five isometric digital sparks positioned above the central crucible valley, representing feature transformations and model weights being forged in real-time.

## 3. Wordmark & Typography

The wordmark is strictly formatted as **MLForge** (one word, capital "M", "L", and "F").

### Primary Typeface: Geist Sans
- **Weights**:
  - Wordmark: **Bold (700)**
  - Tagline: **SemiBold (600)**
  - Letter Spacing: `-0.03em` for wordmark; `+0.14em` for tagline.

### Wordmark Construction
```
[Symbol]   MLForge
           ├── "ML" (Crisp Solid White #f3f4f6)
           └── "Forge" (Vibrant Linear Gradient: Slate Teal #5f8787 → Warm Copper #e78a53 → Luminous Peach #fbcb97)
```

### Official Tagline Lockup
```
Build. Train. Evaluate. Deploy.
```
Positioned below the wordmark in clean muted slate (`#888888`), with uniform spacing celebrating the 4-phase ML lifecycle.

## 5. Clearspace & Minimum Sizing

### Clearspace
The minimum clear space around the logo equals the height of the letter **"M"** (denoted as `X`). No other graphic element, border, or text should infringe upon this perimeter.

```
       ┌───────────────────────────────┐
       │               X               │
       │   ┌──────┐                    │
       │ X │Symbol│  MLForge         X │
       │   └──────┘                    │
       │               X               │
       └───────────────────────────────┘
```

### Minimum Dimensions
- **Full Horizontal Logo**: Minimum width `140px` (digital) or `32mm` (print).
- **Standalone Symbol**: Minimum size `16×16px` (digital favicon) or `8mm` (print).
- **Favicon**: Explicitly optimized for `16×16`, `32×32`, `48×48`, `64×64`.

## 6. Theme & Background Usage

### Dark Backgrounds (Default UI)
- Use **`mlforge-logo-primary.svg`** or **`mlforge-logo-light.svg`**.
- Wordmark is rendered in pure white `#f8fafc` with `Forge` highlighted in Electric Sky `#38bdf8`.
- Standalone symbol uses Electric Sky and Indigo gradients.

### Light Backgrounds
- Use **`mlforge-logo-dark.svg`**.
- Wordmark is rendered in Slate-900 `#0f172a` with `Forge` highlighted in Deep Sky `#0284c7`.
- Standalone symbol uses Deep Sky `#0284c7` and Indigo `#4338ca`.

### Monochrome Applications
- **Dark surfaces / Black-and-white print**: Use `mlforge-logo-monochrome-white.svg`.
- **Light surfaces / Official white papers**: Use `mlforge-logo-monochrome-dark.svg`.

---

## 7. Incorrect Logo Usage

To maintain brand integrity and recognition, never subject the logo to the following distortions:

1. **Do not rotate or skew** the symbol or wordmark.
2. **Do not alter the letter spacing or casing** (e.g. *ML-FORGE*, *MLforge*, *ML FORGE* are strictly prohibited).
3. **Do not add decorative dropshadows, 3D extrusions, or outer neon glows**.
4. **Do not place the full logo on busy, uncurated photographic backgrounds** without an opaque container.
5. **Do not change the facet gradient colors** to unapproved hues (e.g. red, lime green, orange).
6. **Do not substitute the symbol** with emojis, robot heads, or generic circuit boards.
